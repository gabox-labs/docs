`@gabox-labs/sdk` is the TypeScript client for Gabox. It builds every Gabox transaction: launch a coin with its machine, buy packs, sell, claim prizes, and claim earnings. It also reads machines, previews pack prices, and recomputes any draw result.

The SDK uses [Solana Kit](https://github.com/anza-xyz/kit) 7 only. It has no web3.js, bn.js or Buffer, so the same code runs in Node and in the browser.

## Install

```sh
npm install @gabox-labs/sdk @solana/kit
```

- You need Node 24 or newer. The package is ESM only.
- `@solana/kit` 7 is a peer dependency. Your app and the SDK share one copy.

The package has three entry points:

| Import | What is in it |
| --- | --- |
| `@gabox-labs/sdk` | Client, reads, previews, transaction builders, math and settlement |
| `@gabox-labs/sdk/meteora` | Meteora DBC and DAMM v2 accounts, decoders, curve math and the quote registry |
| `@gabox-labs/sdk/generated` | The client generated from the program IDL (interface description): instructions, accounts, events and errors |

## Quick start

Read a machine, preview its packs, and buy the cheapest one:

```ts
import { signAndSendTransactionMessageWithSigners } from '@solana/kit';
import { buyFixedPack, createClient, previewPacks, resolveMachine } from '@gabox-labs/sdk';

const client = createClient({ cluster: 'devnet', url: process.env.RPC_URL });

const machine = await resolveMachine(client, mint);
const { packs } = await previewPacks(client, machine);
const pack = packs[0];

if (pack.enabled) {
  const { message } = await buyFixedPack(client, {
    mint,
    purchaser,       // a Kit TransactionSigner, for example your wallet
    packTier: pack.tier,
    referrer,        // optional, and only used on the buyer's first purchase
  });
  await signAndSendTransactionMessageWithSigners(message);
}
```

Every builder returns a Kit version 0 transaction message. The fee payer, blockhash, compute budget and address lookup tables are already set. You only sign and send it.

`createClient` has no default cluster. Pass `'devnet'`, `'mainnet-beta'` or `'localnet'`. A client refuses an RPC URL from another cluster. Use your own RPC URL for real traffic, because public endpoints limit requests quickly.

## Machine stages

`resolveMachine` returns the machine's stage. The builders choose the right market for each stage, so you never pass a venue yourself.

| Stage | What it means |
| --- | --- |
| `curve` | The coin trades on its Meteora DBC bonding curve. Only Gabox can buy on it. The largest pack (tier 4) is locked. |
| `migrating` | The curve reached its graduation target. Meteora is moving the liquidity, and packs pause. |
| `damm` | The coin trades in a Meteora DAMM v2 pool. Packs work again, and the largest pack (tier 4) unlocks. |
