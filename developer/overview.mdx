The Gabox public API lets your app read every machine, pack, draw and Mega Pack round. It also answers with totals, the program ID and the program's IDL. Reads need no key and no sign-up.

The API serves Solana mainnet. Every answer says which cluster it read in `meta.cluster`.

## Base URL

```text
https://actions.gabox.fun/v1
```

Every route in these pages hangs off this base. The API is the same one that the [developers page](https://gabox.fun/developers) on the website documents. You can run every live request from that page.

## Your first request

Ask for the newest machines. You need no key and no headers.

<CodeGroup>

```bash curl
curl "https://actions.gabox.fun/v1/machines?limit=2"
```

```js JavaScript
const API = "https://actions.gabox.fun/v1"

const res = await fetch(`${API}/machines?limit=2`)
const { data, meta, page } = await res.json()

console.log(meta.cluster)       // "mainnet-beta"
console.log(data[0].mint)       // the newest machine's coin
console.log(page.nextCursor)    // send it back as `cursor` for the next page
```

</CodeGroup>

The API allows calls from any website (CORS is open). You can call it from a browser, a server or a script.

## Every route

These routes are **live**. They answer today.

| Route | What it answers |
| --- | --- |
| `GET /v1/machines` | Every live machine, newest first. |
| `GET /v1/machines/{mint}` | One machine: its stage, pack offer, prize tiers and vault. |
| `GET /v1/machines/{mint}/brief.md` | One machine as Markdown, made for an AI. |
| `GET /v1/machines/{mint}/pulls` | One machine's packs, newest first. |
| `GET /v1/machines/{mint}/mega` | One machine's newest Mega Pack rounds. |
| `GET /v1/pulls/top` | The biggest recent wins on every machine. |
| `GET /v1/draws/{address}` | One draw: waiting, or settled with its result. |
| `GET /v1/stats` | Totals: machines, packs and volume. |
| `GET /v1/program` | The program ID, the pack sizes and the pack fee. |
| `GET /v1/openapi.json` | Every live route, as OpenAPI 3.1. |
| `GET /v1/idl.json` | The Gabox program's Anchor IDL. |

These routes are in **preview**. Gabox documents them with a sample answer, but the API does not serve them yet. Until it does, users take these steps on [gabox.fun](https://gabox.fun). See [Preview calls](/developer/preview-calls).

| Route | What it will do |
| --- | --- |
| `POST /v1/machines/build` | Build a launch transaction. |
| `POST /v1/packs/build` | Build a pack's buy transaction. |
| `GET /v1/fees/{wallet}` | Show a creator's claimable trading fees. |
| `POST /v1/fees/claim/build` | Build one transaction that claims every creator fee. |

## Your keys stay yours

The API only reads, and later it will also build transactions. Your user's wallet signs every transaction. Gabox never asks for a private key or a seed phrase, and it never holds one.

Figures from the API are for display. A pack's buy transaction carries signed limits for the coins and the top prize. The program refuses a result that is worse than those limits. See [Opening a pack](/opening-a-pack#what-you-sign).
