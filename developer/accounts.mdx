Most Gabox accounts are PDAs. A PDA (program derived address) is an address that comes from fixed seeds and a program ID. Nobody holds a private key for it. Only the program that owns it can sign for it.

Every seed below uses the Gabox program ID unless the table says otherwise. A `u64` in a seed is 8 bytes, little-endian.

## Seeds

| Account | Seeds |
| --- | --- |
| `Pool` (the machine) | `["pool", mint]` |
| `Draw` (one pack) | `["draw", pool, purchaser, nonce as u64 LE]` |
| `WalletActivity` | `["activity", wallet]` |
| `QuoteConfig` | `["quote-config", quote_mint]` |
| `Earnings` | `["earnings", wallet, quote_mint]` |
| `ReferralLink` | `["referral", buyer]` |
| Fee authority | `["fees"]`. It has no data. It owns the fee vaults. |
| Fee vault | The ATA of the fee authority for `quote_mint`, under the quote's token program |
| Prize vault | The ATA of `Pool` for the coin mint, under Token-2022 |
| `MegaConfig` | `["mega-config"]` |
| Mega spender | `["mega-spender", pool]`. Never created. Never signs. |
| Mega funding record | `["earnings", spender, quote_mint]`, an `Earnings` account |
| `MegaState` | `["mega", pool]` |
| Mega draw | `["draw", pool, MegaState, draw_index as u64 LE]`, a `Draw` account |
| `MegaClaim` | `["mega-claim", MegaState, wallet]` |
| Reward escrow | The ATA of `MegaState` for the coin mint, under Token-2022 |

An ATA (associated token account) is the standard token account of one owner for one mint.

## Pool

One machine for one coin. `initialize_pool` creates it.

| Field | Meaning |
| --- | --- |
| `creator` | The coin creator. DBC records the same wallet as the curve's creator. |
| `mint`, `vault` | The coin, and the token account that holds the prize inventory. |
| `quote_mint`, `quote_token_program` | The machine's quote token, and the token program that owns it. |
| `dbc_config` | The DBC config the coin launched with. It never changes. |
| `curve_pool` | The DBC curve pool the coin launched on. |
| `reference_valuation` | A reference value of the whole supply, in raw quote units. Clients use it. The program never prices with it. |
| `seed_quote_amount` | The quote the seed buy spent. |
| `tiers` | The prize table: 8 rows of `multiplier_bps` and `tickets`. It never changes. |
| `next_seq` | The sequence number of the next pack. |
| `reserved` | Coins the vault must keep for pending draws and owed prizes. |

## Draw

One pack, from purchase until its prize is paid. The client picks `nonce`, so two purchases never use the same address.

| Field | Meaning |
| --- | --- |
| `pool`, `purchaser`, `nonce` | The machine, the buyer, and the buyer's chosen number. |
| `seq` | The pack's unique sequence number on this machine. The VRF callback must carry it. |
| `request_slot`, `last_attempt_slot`, `attempts` | Timing for retries and expiry. |
| `tiers`, `pack_tokens` | A copy of the prize table and the coins this pack bought. Settlement reads these, not the pool. |
| `free_snapshot` | `vault - reserved` at purchase, before this pack's own coins. |
| `reserved` | What this draw holds in `pool.reserved`. |
| `settled`, `randomness`, `timed_out` | The fixed outcome. `randomness` is all zero after an expiry. |
| `owed` | Coins a claim still has to pay. Zero on the normal path. |

`close_draw` closes a settled draw that owes and reserves nothing. The rent goes back to the purchaser.

## Quote registry and earnings

**`QuoteConfig`** is one quote token that machines may use. Only the platform admin writes it.

| Field | Meaning |
| --- | --- |
| `dbc_config`, `raise` | The registered DBC config, and its graduation raise in raw quote units. |
| `reference_valuation` | Copied into each new machine. |
| `enabled` | False stops new machines on this quote. Existing machines keep trading. |
| `purchases_on` | False stops purchases on every machine of this quote. Pending draws still settle. |
| `mega_on` | True sends the pack fee of a graduated purchase without a referrer to the machine's Mega funding record. |

A machine copies `dbc_config` and `reference_valuation` at launch. A later change affects only new machines.

**`Earnings`** holds one wallet's pack fees in one quote token. The tokens stay in the fee vault until `claim_earnings` pays them. Fields: `wallet`, `quote_mint`, `unclaimed`, and `total_earned` (everything ever earned, claimed or not).

**`ReferralLink`** stores a buyer's referrer. The first purchase that names a referrer creates it. It never changes and never closes. Fields: `buyer`, `referrer`, `bound_slot`.

**`WalletActivity`** counts the packs one wallet bought, on every machine (`packs_bought`).

## Mega Pack accounts

**`MegaConfig`** holds the global Mega settings. Only the platform admin creates and changes it.

| Field | Meaning |
| --- | --- |
| `target_usdc_raw` | The dollar size of one Mega Pack, in 6-decimal USDC units. It lies between `200_000_000` ($200) and `10_000_000_000` ($10,000). |
| `version` | 1 at creation. Every update adds 1. |
| `operator` | The server wallet that opens Mega Packs and publishes roots. It is never the platform admin. |

**Mega funding record.** An ordinary `Earnings` account whose `wallet` is the machine's Mega spender PDA. No instruction signs for the spender, so `claim_earnings` cannot pay this record out. Only `open_mega` can spend it.

**`MegaState`** holds one machine's Mega progress. The first `open_mega` creates it. It is the purchaser of every Mega draw, so Mega prizes land in its reward escrow.

| Field | Meaning |
| --- | --- |
| `next_round`, `funded_rounds` | The next round number, and the rounds that are complete. A round is in progress when `funded_rounds < next_round - 1`. |
| `next_draw`, `first_draw`, `pending_draws` | Mega draw indices, and the draws not finished yet. |
| `round`, `budget`, `config_version`, `target_usdc_raw` | The terms of the latest round, fixed by its first opening. |
| `snapshot_slot`, `snapshot_hash`, `snapshot_id` | The holder snapshot of the latest round: its slot, its SHA-256 hash, and its file id. |
| `opening_complete` | True once `seal_mega_round` ends the round's openings. |
| `last_reward` | The total reward of the latest round's finished draws, in raw coin units. |
| `funded`, `allocated`, `claimed` | Totals in raw coin units. `claimed <= allocated <= funded` always holds. |
| `root`, `root_version`, `root_through_round`, `distribution_id` | The current Merkle root, its version, the last round it covers, and the id of its distribution file. |

**`MegaClaim`** holds one field, `claimed`: the wallet's cumulative amount at its last claim on this machine. Its seeds prove the wallet and the machine. It is never closed.
