---
title: "The math"
description: "The formulas behind packs, prizes and fees"
icon: "calculator"
---

A pack is 1,000,000 coin tokens. The coin has 6 decimals, so the program stores a pack as `1,000,000,000,000` base units. **Basis points** are hundredths of a percent: `10,000 bps = 100% = 1×`.

| Quantity | Formula |
| --- | --- |
| Row prize | `floor(pack_base_units × multiplier_bps / 10,000)` |
| Row chance | `tickets / 65,536`; ticket counts across rows must sum to 65,536 |
| Table average | `Σ(multiplier_bps × tickets) / 65,536`, at most 10,000 bps |
| Mandatory seed | `min(full top prize, 3 × pack) - pack` |
| Free inventory | `vault balance - reserved` |
| First pack top shown | `min(full top prize, free inventory + pack)` |
| Batch reservation | `min(count × full top prize, free inventory + count × pack)` |
| Pack fee | `floor(actual venue quote debit × 75 / 10,000)` |
| Referrer share, if bound | `floor(actual venue quote debit × 50 / 10,000)` |
| Creator pack fee | `pack fee - referrer share` |

The first pack starts with `free inventory + pack` available. For each pack in order, the program pays `min(chosen row prize, available)`, subtracts that payment, then adds one pack for the next pack. A timed-out batch chooses the smallest row for each pack instead of using random tickets.

The venue's 1.25% trading fee is inside its quote. The 0.75% Gabox pack fee is added to that quote. Rounding happens in the quote token's base units. Use a fresh live quote for an actual transaction.
