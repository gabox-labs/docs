---
title: "Trust boundaries"
description: "What code enforces and which services you rely on"
icon: "scale"
---

| Boundary | Rule or dependency |
| --- | --- |
| Gabox program | Checks the launch config, the coin and its transfer fee, the prize table, coin amounts, pack fee, market accounts, reservations and the authenticated callback. Prize coins leave the machine reserve only as prizes, or as a creator withdrawal of coins that creator funded. |
| Transfer fee | Every transfer of a new coin pays 1%. The rate is fixed in the coin for ever. Only the machine can withdraw the fees, and the program moves them only into that machine's own reserve. Anyone can start the collection. |
| Gabox transfer hook | Older coins only. It no longer blocks any transfer, and Meteora removes it at graduation. |
| MagicBlock VRF | Supplies the random bytes. Gabox checks the callback's signer and the draw's sequence number. It relies on MagicBlock to generate the bytes fairly and to deliver them. A late draw can expire at its smallest prize. |
| Meteora | Sets trade prices, runs the curve and the pool, collects trading fees and moves the coin at graduation. Gabox does not compare a trade with an outside price. |
| Gift packs | Only the named wallet can open a gift, once, on its own machine. The gift's USDC can only pay for that one pack. If the opening fails, the gift is unchanged. See [Gift packs](/gift-packs). |
| Swap route | On an older machine not quoted in USDC, the app swaps USDC through Jupiter first. |
| Quote token issuer | Some registered Token-2022 quote tokens, such as stock tokens, let the issuer pause, freeze or move tokens. Gabox refuses quote tokens with transfer fees, live transfer hooks, interest-bearing or rebasing tokens and unknown features. It checks the quote token again at every trade. The issuer can still affect trading and balances. |
| Gabox admin and upgrade authority | The admin registers quote tokens, can stop new machines or purchases on a quote token, and can raise a machine's prize table. The program checks that the new average payout never goes below the old one, and a pack already bought keeps its old table. The admin cannot change a coin's transfer fee. The program can be upgraded, and new code could change machine reserve and draw rules. |
| App server, RPC and indexer | Help you read machines, offers and events, and collect transfer fees on a schedule. Check signed transactions and on-chain data when accuracy matters. |

A quote registry change only applies to machines launched after it. The Gabox admin can raise an existing machine's prize table under the current program, but can never lower its average payout, and an upgrade can still replace that program. See [Deployment status](/status-and-addresses).
