---
title: "Glossary"
description: "Short definitions for the terms used here"
icon: "book"
---

| Term | Meaning |
| --- | --- |
| Machine | One Gabox prize game on one coin, launched together with that coin. Each machine has its own address. |
| Coin | The token a machine pays prizes in. A new coin is a Token-2022 token with 9 decimals, a fixed supply of 1,000,000,000 and a 1% transfer fee. |
| Pack | One purchase at a fixed USDC price, chosen from a fixed range. Its coins are what that price buys on the market. |
| Pack coins | The coins one pack bought, as they arrive in the machine reserve. Every prize is a multiple of them. |
| Prize row | A fixed multiplier and a number of tickets, set at launch. The app calls the rows Common, Rare, Epic and Mythic. |
| Ticket | One of 65,536 equally likely numbers. The random ticket picks a prize row. |
| Draw | One pack, from purchase until its prize is paid or claimed. |
| Machine reserve | The coins a machine pays prizes from. On chain it is the machine's token account, called the vault. |
| Free coins | Machine reserve coins that no open draw or owed prize holds. |
| Reservation | Coins held back in the machine reserve: each open draw's own pack coins, and each owed prize. |
| Seed | Coins the creator buys into the machine reserve at launch. They cannot be taken back. |
| Dev buy | The USDC a creator spends at launch. Part of it is starting liquidity, and the rest buys coins for the creator's own wallet. |
| Starting liquidity | The part of the dev buy that buys the seed. It always covers the mandatory seed. |
| Quote token | The token the coin trades against. Every new coin trades against USDC. Some older machines use SOL, a stock token or another registered Solana token. |
| Pack fee | 2% of the pack price, already inside the price. |
| Trading fee | Meteora's fee inside every trade's price. |
| Transfer fee | 1% of every transfer of a new coin. Token-2022 holds it in the receiving account until it is collected into the machine reserve. Nobody can change the rate. |
| Sweep | Moving collected transfer fees into a coin's machine reserve. Anyone can start it. |
| Referrer | The wallet a buyer named on their first referred purchase. The link is permanent. |
| Gift | A pack bought in advance for one named wallet, on one machine. Only that wallet can open it, once. See [Gift packs](/gift-packs). |
| Bonding curve | The Meteora DBC market a new coin trades on before graduation. Its price rises as coins are bought. |
| Graduation | Meteora moves the coin from the bonding curve into a DAMM v2 pool. |
| AMM | Automated market maker. DAMM v2 is the AMM a coin trades on after graduation. |
| Transfer hook | A Token-2022 rule on older Gabox coins only. New coins have none. |
| VRF | Verifiable random function. MagicBlock supplies the randomness for every draw. |
| PDA | Program derived address: an address computed from fixed seeds and a program ID. Nobody holds a private key for it. |
| ATA | Associated token account: a wallet's standard account for one token. |
| Slot | The Solana clock unit, about 0.27 seconds today. Retry and expiry deadlines count slots. |
| Basis point | One hundredth of one percent. 20 bps is 0.20%. |
