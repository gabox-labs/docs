icon: "book"
---

| Term | Meaning |
| --- | --- |
| Machine | One Gabox prize game tied to one new coin. |
| Pack | 1,000,000 tokens of that coin, bought through its market. |
| Prize row | A fixed multiplier and ticket count chosen by the creator at launch. |
| Ticket | One of 65,536 equally likely numbers that selects a prize row. |
| Draw | One purchase of 1 to 5 packs, from buy through payment or an owed claim. |
| Vault | The machine's token account holding prize inventory. |
| Reservation | Tokens held for pending draws or prizes already owed. |
| Seed | Tokens bought by the creator at launch for the prize vault. |
| Quote asset | The token used to price and pay for a machine's coin, such as WSOL. |
| Bonding curve | The DBC market a new coin uses before graduation. |
| Graduation | DBC's migration into a DAMM v2 liquidity pool. |
| AMM | Automated market maker, the market after graduation. |
| Transfer hook | Token-2022 rule that limits buys from the DBC curve vault to the Gabox machine vault. |
| VRF | Verifiable random function. MagicBlock supplies randomness for draws. |
| PDA | Program derived address, calculated from fixed seeds and a program ID. |
| ATA | Associated token account, a wallet's standard account for one token. |
| Slot | Solana clock unit used for retry and expiry deadlines. |
| Basis point | One hundredth of one percent. 75 bps is 0.75%. |
