Gabox is an onchain gacha for NFTs and tokenized assets. Depositors list real assets in shared pools, buyers pay a fixed ticket price for a verifiably random draw, and every item drawn comes with a guaranteed instant buyback offer.

The whole protocol rests on a single primitive. When a depositor lists an item, they pair it with **backing**: an amount of capital they lock alongside the asset. That one number is simultaneously the item's buyback bid, its draw weight, and the depositor's stake. Everything else, from ticket pricing to draw odds to buyback liquidity, is derived from it.

<Note>
Gabox is a working title. The protocol is in design. This documentation describes the v3 mechanism, the unified backed-position pool.
</Note>

## Why this design matters

Most gacha and lootbox mechanics have a house that can lose. If the protocol promises buybacks from a shared vault, one jackpot cash-out can drain it. Gabox removes that failure mode entirely: every buyback is pre-funded by the depositor's own backing, posted before the item ever enters a pool.

| Property | How Gabox achieves it |
|---|---|
| No insolvency risk | Every possible payout is collateralized by depositor backing before the draw |
| No oracle risk | Prices derive from self-set backing, not floor price feeds |
| Verifiable fairness | Draws use onchain VRF with published odds |
| Guaranteed exit | Every drawn item can be sold back instantly for roughly its backing |

## Scope

- **Assets**: NFTs and tokenized assets only (Collector Crypt cards and similar). No fungible tokens, because a liquid token has a known DEX price that breaks self-set backing. Illiquid uniques have fuzzy floors, so self-backing self-corrects.
- **Chain**: Solana.
- **Randomness**: MagicBlock VRF.
